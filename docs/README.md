## Documentation rules

- Separate public API contracts from implementation details.
- Mark features as implemented, planned, or blocked by external access.
- Never document subscription keys, OAuth credentials, or API tokens.
- Treat each external product's current OpenAPI document as authoritative.
- Update these pages when endpoints, environment variables, tasks, retention,
  or external access change.
